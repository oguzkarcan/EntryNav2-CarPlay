# Runtime shared-library (soname) and symbol manifest for EntryNav2-CarPlay.
#
# Checked by scripts/ci/check_sysroot_symbols.sh:
#   1. Kept strictly in sync with C++ dlopen/dlsym calls under src/ and include/.
#   2. Verified against $SYSROOT (lib, usr/lib, usr/local/lib, opt/hmi/lib).
#
# Directives:
#   library <name> <required|optional> <any|all> [handle=<expr>]
#     required|optional : missing soname fails the check only if required
#     any               : first matching soname candidate satisfies the library;
#                         all symbols must be exported by that resolved soname
#     all               : every soname candidate must exist; each symbol must be
#                         exported by at least one of them (e.g. RTLD_DEFAULT)
#     handle=<expr>     : optional disambiguator when one source file loads
#                         multiple libraries (matches the handle passed to dlsym)
#
#   source <repo-relative-path>
#   soname <filename> [manifest_only]
#   symbol <required|optional> <symbol_name> [manifest_only]
#
# Use `manifest_only` only when a soname/symbol cannot be extracted from C++
# code directly (for example, the host DSOs backing dlsym(RTLD_DEFAULT, ...)).

# Partial sysroot gap: on HU_ENTRYNAV2, libevo_btappl.so lives under
# /opt/app/usr/BTMedia/evolution/stack/lib/libevo_btappl.so via the absolute
# symlink /usr/local/lib/alps/evolution -> /opt/app/usr/BTMedia/evolution/stack/lib,
# which is dangling in the partial sysroot because /opt/app is not included.
# SppSnapshotReader inspects its .dynsym & R_ARM_GLOB_DAT GOT slots read-only via
# /proc/<pid>/{maps,root,mem} (not dlopen). Marked optional in the manifest so the
# partial sysroot check passes while keeping the gap visible.
library libevo_btappl optional any
  source include/carplay/platform/spp_snapshot.hpp
  source src/platform/spp_snapshot.cpp
  soname libevo_btappl.so
  symbol required app manifest_only
  symbol required spp_info manifest_only
  symbol required spp_connected manifest_only
